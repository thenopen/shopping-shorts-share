0. 핵심 발견 3가지

  1. 훅은 반드시 제품/효용과 연관되어야 한다. 제품과 무관한 어그로 훅은 조회수는 만들어도 판매 대목에서 이탈을 만든다 — 틱톡샵 공식 가이드와 더우인 데이터의 공통 결론. 일반 쇼츠 문법과 갈라지는 첫 지점.
  2. 제품 노출 타이밍은 단일 정답이 없다 — 2학파. 효과가 눈에 보이는 저관여 상품은 '첫 프레임에 제품'(제품 선행형), 사연·공감이 필요한 상품은 '40% 지점에 해결책으로 등장'(문제 선행형). 상품 유형이 포맷을 결정.
  3. CTA 문법은 플랫폼 결제 구조가 결정. 인앱 결제(틱톡샵·네이버)는 장바구니 직행 지령, 외부 링크(유튜브 쇼츠+쿠팡)는 고정댓글 유도 + 댓글 수를 노출 연료로 쓰는 설계.

1. 틱톡샵 — 공식 구조와 '제품 노출 타이밍' 2학파

공식훅(3~6초) → 핵심 메시지 → CTA — 틱톡샵 셀러 아카데미
  • 훅: 제품 연관 필수. 무관한 엔터테인먼트 훅은 판매 전환 시점 이탈 유발.
  • CTA: 음성 + 화면 텍스트 둘 다(무음 시청자 대비). 시청 직후 바로 따라 할 수 있는 행동.
  • 공식 인정 4대 포맷: 사용 후기 / 비포&애프터 / 언박싱 / 튜토리얼.
  • 데이터: 독일 상위 셀러 매출 60~70%가 쇼퍼블 비디오+라이브 발생.

3. 더우인(抖音) 커머스 대본 공식 — 최선진 정식화

5단계 인지 모델 (인기 TOP50 데이터 기반 — 가장 정교한 전환 대본 정식화)
  1. 첫 3초 = 인지 충돌 — 제품 소개가 아니라 반상식으로 뇌를 멈춤. 실패례: "안녕하세요, 오늘 소개할 제품은…". 성공례(보온컵): 동료가 컵을 가져가는 이유가 '예뻐서'가 아니라는 반전. 이런 훅은 완주율 평균 대비 +216%.
  2. 4~8초 = 타깃 신원 못박기 — 폭발 대본의 92%가 5초 안에 타깃의 직업·상태·통점 디테일 명시("아침에 뜨거운 두유 담아 출근하는 사무직").
  3. 중반 = 통점 3연문 — ①"~해본 적 있죠?(장면 재현)" ②"그러다 ~됐죠(후과 확대)" ③"이제는요(해결책=제품 등장)". 제품은 감정 사이클이 닫힌 뒤에야 등장.
  4. 증거 = 검증 가능한 미시 증거 — "판매량 10만+", "연예인 pick" 대신 온도계 실측, 방수 실험, 실제 송장 화면. "작지만 진짜인 것이 유명인 추천보다 세다."
  5. 엔딩 = 무사고(無思考) 구매 지령 — 시청자는 결정피로 상태. 생각이 1스텝이라도 필요한 CTA("프로필 가서 봐")는 전멸. 구체 행동+즉시 혜택 병기 시 장바구니 클릭률 4.3배.

4. 고전환 실사례 · 일반 쇼츠와의 차이

실사례 데이터

5. 제품 데모 포맷 6종 — 대본 뼈대

①언박싱형 (신규·생소 제품 — 효능 주장 없이 서스펜스로 판매)
도착 선언/기대감 훅 → 개봉(질감·구성품 클로즈업) → 리얼 첫 반응 → 구성 대비 가격 공개 → CTA
②비포&애프터형 (뷰티·청소·정리 — 효과 가시 상품)
비포(과장 없는 실상) → 제품 3초 등장 → 시연 → 애프터 대비샷 → 가격·혜택 → CTA
③결과 선행형 (효과법)
애프터를 훅으로 → "어떻게 했게?" 정보격차 → 통점 짧게 → 제품+사용법 → 혜택 마감
④가격 공개 연출형 (초저가·가격 우위)
가격 파격 훅/하향 계단식 → 물량·실물 전시 → 즉석 품질 테스트 → 무배·사은품 → 주문 지령
⑤후기·리뷰형 (신뢰 자산 있는 계정)
문제 서사(40% 룰) → 7~15초 제품 첫 접촉 → 구체 수치 주장 → 미시 증거 → 실가격 긴급성 CTA
⑥튜토리얼형 (사용법이 곧 셀링포인트)
"~하는 법" 훅 → 단계별 시연(단계=기능 1개) → 완성 결과 → 태그/링크 CTA
