1. 검증된 대본 공식/구조

표준Hook → Problem → Solution → CTA (60초 기준 초 배분)
  • Hook (0~3초) — 강한 한 문장·결과 선공개. 예: "이 영상 하나로 매출이 두 배가 됐어요"
  • Problem (3~10초) — 문제 제시 한 번에
  • Solution (10~40초) — 갈등→시도→변화의 미니 서사
  • 요약·CTA (마지막 10초) — 감정 회수 + 행동 유도

실무 체크법: 문장마다 "이건 훅인가, 서사인가, 전환인가, 회수인가?" 자문.

3. AI 대본 툴들의 프롬프트 Good Case

4. 카테고리별 소구 문법

뷰티공감 상황 + 숫자 + 감각어
  • 일상 공감: "밤새 쌓인 노폐물, 운동 후 피지까지"
  • 숫자 신뢰: "48시간 무너지지 않는 메이크업" / "사용 10일 차부터 달라지는 피부 결" — "깊은 보습"보다 "11중 수분 침투"
  • 감각어: "피지 순삭", "깊숙이 스며드는", "보들보들한"
  • 콘텐츠 유형: 비포&애프터, 제형·발림감 클로즈업
⚠ 화장품법 금지: "여드름 치료", "트러블 개선", "아토피 완화", "피부 재생"(의약품 오인), "업계 최초", "100% 천연"(무인증). 대체: 치료→"피부 결 정돈", 개선→"피부 진정". 대한화장품협회 광고자문 기준 참조.
GENCY Studio · 다플랜
식품감각 자극 + 상황 소환 — 릴스 최고 인기 주제(44.1%). ASMR 먹방·짧은 레시피·꿀조합. 카피: "밥을 부르는 치킨" / "입은 즐겁게 몸은 가볍게".
생활용품불편 공감 질문 → 한 번에 해결 — "텀블러 대충 씻고 계신가요? 한 알이면 충분해요" / "누구나 예쁜집에 살수있어"(오늘의집).
가전스펙의 감성 번역 — 기능이 바꾸는 생활 장면: "화질이 좋아지면 보는 표정까지 밝아집니다"(삼성 파브). 퍼포먼스형은 할인 숫자 선행.
패션비주얼이 곧 소구 — 체형별 핏 비교·360도 디테일·"아이템 하나로 3가지 스타일링". W컨셉 숏폼 도입 후 구매 전환율 6.2%(일반 대비 4배).
공통 출처: 다플랜 — 업종별 숏폼 가이드 · 토스페이먼츠 · 채널톡 카피 222 · imweb 사례집
공통 원칙: 카피는 하나의 메시지만. 최다 실수 = 많은 내용을 다 담으려는 것. 담을 후보 5요소: 제품 장점 / 필요한 상황 공감 / 프로모션 / 이벤트 / 브랜드 메시지 — 이 중 하나만 고른다.

5. LLM 프롬프트 엔지니어링 모범 사례

CO-STAR (GovTech 프롬프트 대회 우승 구조) — Context / Objective / Style / Tone / Audience / Response format. 광고 대본이면: 제품·시장 맥락 → 전환 목표 → 숏폼 구어체 → 톤 → 타겟 페르소나 → 초 단위 표 형식 출력 지정.
brunch — 프롬프트 6요소
와디즈 디렉터의 6단계 협업 프로세스
  1. 역할 지정 + 역할 이해 확인
  2. 타깃 도출 — 구체적 숫자로 요구("타깃 5가지")
  3. 역설계 — 제품 특징을 먼저 말하지 말고 "그 타깃에게 어필하려면 어떤 특징이 중요할지" 역으로 질문
  4. 변수 추가 — 시즌·타깃만의 페인 포인트
  5. 카피 작성 의뢰
  6. 수정 — 구체적 숫자로 가이드, 표현 방식 변경으로 새 콘셉트

철학: "챗GPT와 협업하세요, 의존하지 말고" — 최종 킬러 콘셉트는 사람이 보탠다.

패션포스트 — 콘텐츠 디렉터의 10분 카피
Few-shot과 제약 조건
  • 잘 쓴 카피 예시를 먼저 주고 시작 — "예시 데이터가 잘 정리돼 있으면 AI는 엄청난 결과물을 출력"
  • 나쁜 예 → 좋은 예: "콜라 카피 만들어줘" → "제로 슈가 콜라를 2~30대에게 팔고 싶어. 홍보 카피 한 줄"(타겟+제품+분량)
  • 초 단위 구조를 프롬프트에 강제 + "각 파트 몇 초인지 명시" 요구
  • 규제(화장품법 등) 금지 표현을 negative constraint로 명시, 대체 표현 매핑을 few-shot으로
아이보스 · TBWA · AdLibrary
변형 대량 생성 + 단일 변수 테스트 — Arcads·Creatify 공통: 훅 5~10개 변형(바디 고정) → 훅 A/B → 이긴 훅으로 앵글 테스트 → 한 번에 한 변수만. LLM엔 "같은 구조로 훅만 다른 N개" 형태로 이식.
