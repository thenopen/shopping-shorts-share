# 시스템 구조 (개발자용)

> 이 문서 = "우리가 뭘 만드는가"의 지도.
> 동생(코딩 도움)이 처음 읽는 문서. 코드 디테일보다 **전체 그림**.

## 한 줄 요약

도우인(중국 틱톡) 상품영상 링크 → 자동으로 **한국어 쇼핑 쇼츠**로 변환하는 서비스.
웹앱 + 데스크톱앱 둘 다 제공, **구독료** 받는 유료 SaaS가 목표.

## 사용자가 보는 흐름

```
1. 도우인 영상 링크 붙여넣기
2. 성우 / 폰트 / CTA / 템플릿 설정
3. "작업 시작" 클릭
4. (자동) 다운로드 → 자막제거 → 더빙 → 자막생성 → BGM → 합성
5. 완성된 9:16 쇼츠 mp4 다운로드
6. 틱톡에 업로드 → 제휴링크로 수익
```

## 영상 변환 파이프라인 (엔진 핵심)

```
[도우인 링크]
   │
   ▼  yt-dlp
[1] 다운로드 + 분석 (해상도/길이/자막유무)
   │
   ▼  ffmpeg
[2] 원본 사운드 제거
   │
   ▼  ffmpeg (작은글씨=blur, 큰글씨=박스 덮기)
[3] 중국어 자막 제거
   │
   ▼  mediapipe 얼굴탐지
[4] 얼굴 크게 잡힌 컷 잘라내기 (제품샷 위주로)
   │
   ▼  edge-tts (무료, 성우선택+배속)
[5] 한국어 TTS 더빙
   │
   ▼  ASS 자막 (구간별 폰트/사이즈/그라데이션/테두리/쉐도우)
[6] 자동 자막 생성 (TTS 타임스탬프로 싱크)
   │
   ▼  ffmpeg 믹싱 (무료 음원)
[7] BGM + 효과음
   │
   ▼  drawtext/ASS
[8] CTA 멘트 (고정댓글/프로필링크/하단링크)
   │
   ▼  ffmpeg 인코딩
[9] 9:16 세로 mp4 완성
```

이 파이프라인 코드 = `packages/core/app/pipeline/`. 단계마다 파일 1개.

## 시스템 구성 (모노레포)

```
쇼핑쇼츠/
├── packages/
│   ├── core/      ← 영상처리 엔진 (Python). 로컬·서버 공용.
│   │              CLI로도 단독 실행 가능. 이게 심장.
│   ├── server/    ← SaaS 백엔드 (Python/FastAPI).
│   │              인증·구독결제·작업큐·core 호출.
│   ├── web/       ← 웹앱 (Next.js). 브라우저용.
│   └── desktop/   ← 데스크톱앱 (Tauri). 로컬처리 가능.
└── shared/        ← 웹·데스크톱·서버 공통 타입/스키마
```

## 처리 위치 = 하이브리드 (핵심 설계 결정)

| 클라이언트 | 처리 위치 | 이유 |
|-----------|----------|------|
| 데스크톱앱 | **로컬 PC** (core 직접 실행) | 서버비 0, 빠름, 헤비유저용 |
| 웹앱 | **서버** (server가 core 호출) | 설치 불필요, 가벼운 사용자용 |

→ 같은 `core` 엔진을 양쪽에서 재사용. 그래서 core를 독립 패키지로 분리.

## 단계별 출시 계획

```
[지금]  로컬에서 core CLI 동작 검증
   ▼
[샘플]  GitHub에 구조+골격 올림 ← 동생과 협업 시작점 (현재 목표)
   ▼
[베타]  몇백명 오픈베타. 웹앱 + 데스크톱 배포
   ▼
[정식]  구독결제(토스/카카오/Stripe) 켜고 유료화
```

## 무료 기술 스택

| 기능 | 도구 | 비용 |
|------|------|------|
| 다운로드 | yt-dlp | 무료 |
| 영상합성 | ffmpeg | 무료 |
| TTS 더빙 | edge-tts (MS 뉴럴) | 무료, API키X |
| 자막효과 | ASS 자막 (libass) | 무료 |
| 얼굴탐지 | mediapipe | 무료 |
| 데스크톱셸 | Tauri (Rust+React) | 무료 |
| 웹 | Next.js | 무료 |
| 백엔드 | FastAPI | 무료 |

> ⚠️ 개발은 무료지만 SaaS **서버 운영비는 발생**(웹앱 영상처리). 구독료로 충당.
> ⚠️ edge-tts 상업적 대량사용은 약관 회색지대 → 베타 후 Piper(로컬TTS) 등 검토.

## 동생이 시작할 곳

1. 이 문서로 전체 그림 파악
2. `packages/core/app/pipeline/` — 각 파일 docstring 읽으면 단계별 역할 보임
3. `packages/core/app/pipeline/run.py` — 전체를 잇는 오케스트레이터
4. `python -m app.pipeline.tts` — 무료 TTS 동작 확인 (제일 쉬운 검증)
