# 올리브영 쇼핑 큐레이터 (제휴 수익화)

> 레퍼런스. 완성 쇼츠에 붙일 제휴링크 수익구조 중 하나.
> (스크린샷: "올리브영 쇼핑 큐레이터 활동 가이드")

## 큐레이터란
- 올리브영이 운영하는 콘텐츠 수익화 프로그램
- **올리브영 회원이면 누구나 시작 가능**
- 내 상품 링크 발급 → 홍보 → 링크로 구매 발생 시 구매금액 일부를 수익으로
- 셔터 게시물에 부착한 상품 태그로 구매 발생해도 수익

## 활동 단계
1. **활동하기**: 상품 링크 발행 → 내 채널에 공유 / 셔터 게시물 작성 + 상품 태그 부착
2. **실적 확인**: 전일 발생 수익을 매일 오전 9시에 큐레이터 대시보드에서 확인
3. **최종 승인**: (지급 관련 — 스크린샷 하단 잘림)

## 수수료 (강의 정보 기준)
- 올리브영 큐레이터 = **7%** (쿠팡파트너스 3%보다 높음)
- 내가 소개한 상품 외 다른 상품 구매돼도 **3%** 추가 수익
- 다이소 제품 = 쿠팡스, 올리브영 제품 = 올리브영 큐레이터로 수익 극대화

## 앱 연동 (Phase 4 제휴링크 관리)
- 완성된 쇼츠마다 제휴링크 매핑 (쿠팡파트너스 / 올리브영 큐레이터 / 오늘의집 / 알리 / 테무)
- 업로드 캡션에 링크 자동삽입
- 하나의 영상에 여러 수익구조 동시 적용
