# AE / 편집 소스 (DREAM 템플릿 세트)

영상 편집·쇼츠 오버레이용 원본 에셋 모음. **Git LFS로 관리**(zip, 파일당 최대 2GB) —
용량이 커서 일반 커밋이 불가한 바이너리라 `.gitattributes`에서 `ae-sources/*.zip`을 LFS 트래킹한다.

> ⚠️ 클론 시 실제 zip을 받으려면 `git lfs pull` 필요(LFS 미설치면 포인터 파일만 받아짐).
> LFS 설치: `git lfs install`.

## 자동 파이프라인 통합 관점

우리 `packages/core`의 자동 파이프라인은 **ffmpeg + libass** 기반(사람 손 없이 링크→완성 mp4).
After Effects/Premiere는 GUI 수동 편집 툴이라 파이프라인이 직접 실행하지 못한다. 따라서:

- **✅ 직접 오버레이(png·알파 mov)**: 말풍선·트랜지션·ㅋㅋㅋ는 이미 결과물 소스라 `compose`에
  오버레이 트랙으로 얹으면 그대로 재활용된다(모방 불필요). → 통합 대상.
- **🎨 룩 참고(.aep·.mogrt·3D)**: AE/Premiere 전용 효과는 렌더 결과의 룩만 보고 우리 자막/효과
  엔진(libass 스타일·등장 효과)으로 **가능한 선에서 근사 재현**한다.
